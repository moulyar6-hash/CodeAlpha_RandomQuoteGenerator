# 💬 Random Quote Generator

An Android application that displays inspiring quotes to motivate users, built using **Kotlin** and **Jetpack Compose**.

## ✨ Features
- Display inspirational quotes
- Generate a new quote with a button
- Simple and user-friendly interface
- Clean Android application design

## 🛠️ Technologies Used
- Kotlin
- Android Studio
- Jetpack Compose
- Gradle

## 📱 Application
The Random Quote Generator helps users discover motivational quotes through a simple and interactive Android app.

## 🚀 How to Run
1. Clone or download this repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Connect an Android device or start an emulator.
5. Click **Run ▶️** to launch the application.
